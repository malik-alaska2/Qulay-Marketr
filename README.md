# Qulay Market — каталог на GitHub Pages

Сайт: **https://malik-alaska2.github.io/Qulay-Marketr/**

Работает без сервера — как E-BAZAR. Страница, данные и фотографии лежат прямо в этом репозитории, GitHub раздаёт их бесплатно. Ни VPS, ни базы данных, ни Docker.

Интерфейс полностью на узбекском. Жильё и товары в одном каталоге, цены в турецких лирах, связь с покупателем — кнопкой «Telegramga yozish».

---

## Что где лежит

```
index.html      весь каталог: витрина, карточка позиции, избранное, бошкарув панели
catalog.json    позиции, настройки и данные для входа
api/bot.js      обработчик Telegram-бота (Vercel), шлёт рекламу на /start
api/reviews.js  ящик для новых отзывов (Vercel + Redis), пока не одобрены
photos/         фотографии
logo.png        полный логотип (экран входа)
icon.png        знак магазина (шапка и иконка вкладки)
```

## Вход в админку

Открыть сайт → **5 нажатий на логотип** (или адрес с `#admin`) → логин и пароль.

- Логин: `admin`
- Пароль: `Istanbul2026`

Логин и пароль меняются в самой мини-аппе: раздел **Kirish ma'lumotlari** → новый пароль дважды → **Hammasini saqlash**. Пароль хранится в `catalog.json` не открытым текстом, а в виде PBKDF2-хэша (200 000 итераций) со случайной солью.

## Ключ GitHub

Пароль открывает панель, но записывать изменения в репозиторий может только ключ GitHub. Он вводится один раз на каждом устройстве и хранится только в браузере.

1. https://github.com/settings/tokens?type=beta → **Generate new token**
2. **Expiration** — `No expiration`
3. **Repository access** → *Only select repositories* → **Qulay-Marketr**
4. **Permissions** → *Repository permissions* → **Contents** → **Read and write**
5. Вставить в разделе **GitHub kaliti**

## Что можно менять в панели

- **Do'kon** — название каталога, Telegram для связи (без `@`), телефон
- **Transfer / taksi** — включение раздела, Telegram и телефон таксиста, описание, список направлений, прайс
- **Bot reklamasi** — реклама, которую бот шлёт на `/start`: фото, заголовок, текст, кнопки; отдельно узбекская и русская версии — у каждой своя картинка
- **Sharhlar** — новые отзывы людей: «Chiqarish» — вывести на сайт, «O'chirish» — удалить; ниже список тех, что уже на сайте
- **Kirish ma'lumotlari** — логин и пароль
- **E'lonlar** — тип (uy-joy / mahsulot), название, цена, описание, категория, район, комнаты, площадь, этаж, скрытие с сайта
- Для жилья дополнительно: **Qo'shimcha ma'lumotlar** — адрес, возраст дома, отопление, техника, транспорт, дата объявления; **Ijara sharti** — депозит, комиссия, минимальный срок; **Uyda bor** — мебель, лифт, балкон, парковка, интернет, коммуналка в цене, животные
- **Suratlar** — с телефона, сжимаются в браузере до 1280 px
- Порядок — стрелками ↑ ↓, удаление — кнопкой

Внизу — **Hammasini saqlash**. GitHub обновляет сайт примерно за минуту.

## Раздел «Transfer» (такси)

Второй пункт нижнего меню. Это не каталог, а форма заказа: **Qayerdan → Qayerga** (с подсказками из списка направлений и кнопкой обмена местами), дата, время, число пассажиров, багаж и комментарий. Кнопка **«＋ To'xtash joyi qo'shish»** добавляет промежуточные остановки — до четырёх; каждая убирается крестиком, обмен местами разворачивает весь маршрут. Кнопка **«Telegram orqali buyurtma»** открывает чат таксиста с уже готовым текстом заказа; вторая кнопка копирует тот же текст в буфер.

Таксист по умолчанию — **@ist2015**, меняется в панели, раздел **Transfer / taksi**. Там же:

- галочка **«Bo'lim saytda ko'rsatilsin»** — выключает раздел целиком (пропадает из меню и с баннера в каталоге);
- **Yo'nalish variantlari** — по одному месту в строке, это подсказки в полях «откуда/куда» (вводить можно и своё);
- **Narxlar** — по строке `направление | цена`; если поле пустое, таблица цен на странице не показывается.

Настройки лежат в `catalog.json` → `settings.transfer`.

## Бот: реклама при входе

Сам бот — только кнопка Menu Button, отвечать он не умел. Теперь в репозитории лежит `api/bot.js` — serverless-функция Vercel (репозиторий уже подключён к Vercel, деплой автоматический, сервер не нужен). На `/start` бот сначала спрашивает язык («🇺🇿 O‘zbekcha / 🇷🇺 Русский»), а потом присылает рекламу на выбранном языке: фото, заголовок, текст и кнопки — всё из `catalog.json` → `settings.promo` (русский вариант — `settings.promo.ru`).

Картинка тоже своя для каждого языка: узбекская — `settings.promo.photo` (`photos/bot-banner-uz.jpg`), русская — `settings.promo.ru.photo` (`photos/bot-banner-ru.jpg`). Если русская не задана, отправляется узбекская. Обе меняются в панели: **Bot reklamasi** → «Surat — o'zbekcha» и «Surat — ruscha».

Кнопки задаются строками `matn | havola`, до шести штук:

| Havola | Что делает |
| --- | --- |
| `app` | открывает мини-апп |
| `app#transfer` | открывает раздел «Transfer» |
| `@nik` | переход в Telegram-профиль |
| `https://…` | обычная ссылка |

`app#transfer` превращается в `?p=transfer`, а не в якорь: Telegram затирает `#` в адресе мини-аппа своими данными (`#tgWebAppData=…`), поэтому раздел передаётся параметром запроса. `index.html` понимает оба варианта.

Всё это правится в панели управления, раздел **Bot reklamasi** (включение, фото и тексты — отдельно для узбекского и русского). Если фото не отправилось, бот автоматически шлёт то же самое текстом.

### Текст до нажатия Start

Когда человек только открывает бота, Telegram показывает по центру пустого чата описание бота и большую кнопку START. Этот текст тоже правится в панели (**Tavsif** и **Qisqa tavsif**) и уходит в Telegram через `setMyDescription` / `setMyShortDescription`, когда открывают `/api/bot?setup=1`.

Картинку над этим текстом Bot API менять не умеет — она ставится только вручную: **@BotFather → /mybots → бот → Edit Bot → Edit Description Picture**, размер строго 640×360. Готовые файлы лежат в репозитории: `photos/bot-banner-uz.jpg` и `photos/bot-banner-ru.jpg` (это версии 1280×720 для сообщения; для BotFather нужен вариант 640×360 — картинка в профиле одна, независимо от языка).

### Где это живёт

Проект на Vercel — **qulay-market-bot** (аккаунт malik.alaska2), адрес <https://qulay-market-bot.vercel.app>. Отдельный старый проект `qulay-marketr.vercel.app` лежит на другом аккаунте Vercel и к боту отношения не имеет.

### Подключение — один раз

1. Vercel → проект → **Settings → Environment Variables** → добавить `BOT_TOKEN` = токен из BotFather. По желанию `WEBHOOK_SECRET` = любая строка (защита от чужих запросов). Затем **Redeploy**.
2. Открыть <https://qulay-market-bot.vercel.app/api/bot?setup=1> — функция сама зарегистрирует вебхук своим же адресом, взяв токен из переменной окружения. Токен при этом никуда не передаётся и в браузере не виден. В ответе должно быть `"setWebhook":{"ok":true,"result":true,…}`.
3. Написать боту `/start` — придёт реклама.

Обычный GET без `?setup=1` показывает состояние: имя бота, текущий адрес вебхука, число необработанных апдейтов и последнюю ошибку Telegram. Тот же адрес с `?setup=1` можно открыть повторно, если вебхук когда-нибудь слетит. Подменить адрес вебхука через этот эндпоинт нельзя — он всегда ставит сам себя.

Отключить рекламу можно галочкой в панели, не трогая вебхук.

## Раздел «Mahsulotlar» временно закрыт

В `index.html` есть строка:

```js
const SHOW_PRODUCTS = false;
```

Пока там `false` — кнопка «Mahsulotlar» в нижнем меню не показывается, товары не выводятся ни в каталоге, ни в избранном. Чтобы вернуть раздел, достаточно поменять на `true`. В панели управления тип «Mahsulot» остаётся на месте.

## Ссылки: чем делиться

У бота два разных адреса, и это важно:

| Ссылка | Что делает |
| --- | --- |
| `https://t.me/QulayMarketr_Bot` | открывает **чат** с ботом — Telegram показывает страницу с кнопкой **START BOT**, приложение с неё не запускается |
| `https://t.me/QulayMarketr_Bot/app` | открывает **мини-апп** сразу, в одно нажатие — это и есть ссылка для рассылки |

Вторая ссылка работает потому, что в **@BotFather → Bot Settings → Configure Mini App** задан короткий адрес `app`. Если открыть любую `t.me/…` ссылку не в Telegram, а в обычном браузере, сначала всегда покажется промежуточная страница Telegram с кнопкой — запустить приложение из браузера нельзя.

### Ссылка на конкретное место в приложении

К адресу приложения добавляется `?startapp=`, значение — `[язык_]раздел`:

| Ссылка | Куда открывает |
| --- | --- |
| `t.me/QulayMarketr_Bot/app` | каталог |
| `…/app?startapp=transfer` | раздел «Transfer» |
| `…/app?startapp=item-3` | объявление №3 |
| `…/app?startapp=ru_item-3` | то же объявление, интерфейс на русском |
| `…/app?startapp=ru` | каталог на русском |
| `…/app?startapp=saralangan` | избранное |

Язык из ссылки запоминается в браузере, дальше человек может переключить его сам кнопкой **UZ / RU** в шапке.

Кнопка **«E'lon havolasini nusxalash»** под объявлением копирует именно такую телеграмную ссылку — с номером объявления и текущим языком. Сам сайт по-прежнему открывается и напрямую: `.../Qulay-Marketr/#item-3`.

## Статистика: сколько людей заходят и смотрят объявления

Под каждым объявлением — и в каталоге, и на самой карточке — показывается «👁 N»: **сколько разных людей** его открыло. Значок появляется только когда просмотры есть. Полные цифры — в панели управления, раздел **Statistika** (самый верхний):

- сколько людей заходило в мини-апп и сколько всего было открытий;
- сколько людей нажимало `/start` в боте и сколько запусков всего;
- выбор языка — отдельно в боте и в приложении;
- столбики за последние 14 дней;
- список объявлений, отсортированный по просмотрам: «3 odam · 5 marta».

Один человек считается **раз в 10 минут** — обновление страницы счётчик не накручивает. О человеке ничего не хранится: в браузере лежит случайная метка, нужная только чтобы не посчитать одного дважды; для бота — числовой id, по которому имя не восстановить.

### Что где лежит

| Файл | Роль |
| --- | --- |
| `api/_store.js` | подключение к Redis (REST), общее для бота и статистики |
| `api/stats.js` | `POST` — записать просмотр, `GET` — отдать все цифры |
| `index.html` | отправляет события, рисует «👁 N» и раздел **Statistika** |

Адрес счётчика задан в `index.html` → `CONFIG.stats.url`. Если стереть его, статистика просто отключится, сайт продолжит работать.

### Подключение хранилища (один раз, ~5 минут)

Пока хранилище не подключено, всё работает по-старому, а в панели видно предупреждение и нули.

1. **vercel.com** → проект **qulay-market-bot** → вкладка **Storage** → **Create / Browse Marketplace** → **Upstash** → **Redis**.
2. План — **бесплатный**, регион — ближайший к Европе (например `eu-west-1`), имя любое.
3. **Connect to Project** → выбрать `qulay-market-bot`, все окружения (Production, Preview, Development).
4. Vercel сам добавит в проект переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` — копировать ничего не нужно.
5. **Deployments** → у последнего деплоя **⋯ → Redeploy**.

Проверка: открыть <https://qulay-market-bot.vercel.app/api/stats> — должно быть `"store": true`. После этого счётчики начинают расти, а в панели пропадает предупреждение.

Расход на бесплатном тарифе: один просмотр объявления — около 5 команд Redis, одно открытие приложения — 4. Даже при тысяче просмотров в день до лимита далеко.

## Отзывы: где лучше — жильё или такси

Четвёртый пункт нижнего меню — **Sharhlar / Отзывы**. Наверху две карточки рядом: **Уy-joy** и **Transfer / taksi**, у каждой средняя оценка, звёзды и число отзывов; у той, что выше, — метка «Eng yuqori baho». Ниже — сами отзывы (фильтр «Все / Жильё / Трансфер») и форма «Sharhingizni yozing».

Средняя оценка видна и в других местах: на карточке объявления в каталоге (★ 4.8 (3)), на странице объявления и в разделе «Transfer» — там же три последних отзыва и кнопка «Sharh qoldirish».

В форме человек выбирает, о чём отзыв: **Transfer / taksi**, **Уy-joy (в целом)** или конкретное объявление из списка; ставит от 1 до 5 звёзд, пишет имя и текст. Один человек — один отзыв в сутки на один раздел.

### Отзыв появляется только после вашего одобрения

Отправленный отзыв уходит в «ящик» — `api/reviews.js` (тот же Upstash Redis, что и статистика) — и на сайте его ещё не видно. В панели управления раздел **Sharhlar** показывает, сколько пришло новых:

- **Chiqarish** — отзыв переезжает в `catalog.json` и после **Hammasini saqlash** виден всем;
- **O'chirish** — отзыв пропадает;
- у отзывов, уже стоящих на сайте, есть **Yashirish** (временно убрать) и **O'chirish**.

Оба действия вступают в силу только после **Hammasini saqlash** — тогда же ящик очищается. Галочка «Bo'lim saytda ko'rsatilsin» убирает раздел целиком (настройка лежит в `catalog.json` → `settings.reviews.on`, сами отзывы — в `reviews`).

Отдельно ничего подключать не нужно: хранилище то же, что у статистики. Если оно вдруг отключится, отзывы с сайта никуда не денутся (они в `catalog.json`), просто новые отправить не получится — в панели будет предупреждение.

По желанию можно закрыть ящик от чужих глаз: в Vercel → Settings → Environment Variables добавить `REVIEWS_KEY` — тогда читать и чистить ящик можно будет только с этим ключом (в адресе `?key=…`). Без переменной всё работает как есть.
