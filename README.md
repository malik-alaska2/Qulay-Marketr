# Qulay Market — каталог на GitHub Pages

Сайт: **https://malik-alaska2.github.io/Qulay-Marketr/**

Работает без сервера — как E-BAZAR. Страница, данные и фотографии лежат прямо в этом репозитории, GitHub раздаёт их бесплатно. Ни VPS, ни базы данных, ни Docker.

Интерфейс полностью на узбекском. Жильё и товары в одном каталоге, цены в турецких лирах, связь с покупателем — кнопкой «Telegramga yozish».

---

## Что где лежит

```
index.html      весь каталог: витрина, карточка позиции, избранное, бошкарув панели
catalog.json    позиции, настройки и данные для входа
photos/         фотографии
logo.png        полный логотип (экран входа)
icon.png        знак магазина (шапка и иконка вкладки)
```

## Вход в админку

Открыть сайт → **5 нажатий на логотип** (или адрес с `#admin`) → логин и пароль.

- Логин: `admin`
- Пароль: `Istanbul2026`

Логин и пароль меняются в самой мини-аппе: раздел **Kirish ma'lumotlari** → новый пароль дважды → **Hammasini saqlash**. Пароль хранится в `catalog.json` не открытым текстом, а в виде PBKDF2-хэша (200 000 итераций) со случайной солью.

## Ключ GitHub

Пароль открывает панель, но записывать изменения в репозиторий может только ключ GitHub. Он вводится один раз на каждом устройстве и хранится только в браузере.

1. https://github.com/settings/tokens?type=beta → **Generate new token**
2. **Expiration** — `No expiration`
3. **Repository access** → *Only select repositories* → **Qulay-Marketr**
4. **Permissions** → *Repository permissions* → **Contents** → **Read and write**
5. Вставить в разделе **GitHub kaliti**

## Что можно менять в панели

- **Do'kon** — название каталога, Telegram для связи (без `@`), телефон
- **Transfer / taksi** — включение раздела, Telegram и телефон таксиста, описание, список направлений, прайс
- **Kirish ma'lumotlari** — логин и пароль
- **E'lonlar** — тип (uy-joy / mahsulot), название, цена, описание, категория, район, комнаты, площадь, этаж, скрытие с сайта
- Для жилья дополнительно: **Qo'shimcha ma'lumotlar** — адрес, возраст дома, отопление, техника, транспорт, дата объявления; **Ijara sharti** — депозит, комиссия, минимальный срок; **Uyda bor** — мебель, лифт, балкон, парковка, интернет, коммуналка в цене, животные
- **Suratlar** — с телефона, сжимаются в браузере до 1280 px
- Порядок — стрелками ↑ ↓, удаление — кнопкой

Внизу — **Hammasini saqlash**. GitHub обновляет сайт примерно за минуту.

## Раздел «Transfer» (такси)

Второй пункт нижнего меню. Это не каталог, а форма заказа: **Qayerdan → Qayerga** (с подсказками из списка направлений и кнопкой обмена местами), дата, время, число пассажиров, багаж и комментарий. Кнопка **«＋ To'xtash joyi qo'shish»** добавляет промежуточные остановки — до четырёх; каждая убирается крестиком, обмен местами разворачивает весь маршрут. Кнопка **«Telegram orqali buyurtma»** открывает чат таксиста с уже готовым текстом заказа; вторая кнопка копирует тот же текст в буфер.

Таксист по умолчанию — **@ist2015**, меняется в панели, раздел **Transfer / taksi**. Там же:

- галочка **«Bo'lim saytda ko'rsatilsin»** — выключает раздел целиком (пропадает из меню и с баннера в каталоге);
- **Yo'nalish variantlari** — по одному месту в строке, это подсказки в полях «откуда/куда» (вводить можно и своё);
- **Narxlar** — по строке `направление | цена`; если поле пустое, таблица цен на странице не показывается.

Настройки лежат в `catalog.json` → `settings.transfer`.

## Раздел «Mahsulotlar» временно закрыт

В `index.html` есть строка:

```js
const SHOW_PRODUCTS = false;
```

Пока там `false` — кнопка «Mahsulotlar» в нижнем меню не показывается, товары не выводятся ни в каталоге, ни в избранном. Чтобы вернуть раздел, достаточно поменять на `true`. В панели управления тип «Mahsulot» остаётся на месте.
