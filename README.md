# Qulay Market — каталог на GitHub Pages

Сайт: **https://malik-alaska2.github.io/Qulay-Marketr/**

Работает без сервера — как E-BAZAR. Страница, данные и фотографии лежат прямо в этом репозитории, GitHub раздаёт их бесплатно. Ни VPS, ни базы данных, ни Docker, ни оплаты хостинга.

Жильё и товары в одном каталоге, цены в турецких лирах, связь с покупателем — кнопкой «Написать в Telegram».

---

## Что где лежит

```
index.html      весь каталог: витрина, карточка позиции, избранное, админка
catalog.json    позиции и настройки (обновляется из админки)
photos/         фотографии
```

## Как открыть админку

Откройте сайт и **нажмите 5 раз подряд на логотип «Qulay Market»** — или добавьте `#admin` к адресу.

Чтобы админка могла сохранять изменения, ей нужен ключ доступа GitHub. Создаётся один раз:

1. Откройте https://github.com/settings/tokens?type=beta → **Generate new token**
2. Заполните:
   - **Token name** — любое, например `qulay-market`
   - **Expiration** — `No expiration` (или год)
   - **Repository access** → *Only select repositories* → выберите **Qulay-Marketr**
   - **Permissions** → *Repository permissions* → **Contents** → **Read and write**
3. **Generate token** → скопируйте ключ (он показывается один раз)
4. Вставьте его в админку и нажмите «Войти»

Ключ сохраняется только в вашем телефоне или браузере — в репозитории его нет.

## Что можно менять в админке

- **Настройки** — название каталога, Telegram для связи (без `@`), телефон
- **Позиции** — тип (жильё / товар), название, цена, описание, категория, район, комнаты, площадь, этаж, мебель
- **Фотографии** — с телефона, сжимаются прямо в браузере до 1280 px
- **Скрыть с сайта** — позиция остаётся в базе, но не видна посетителям
- Порядок — стрелками ↑ ↓, удаление — кнопкой

Внизу — **«Сохранить всё»**. После сохранения GitHub обновляет сайт примерно за минуту.

## Включить сайт (один раз)

**Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**
Через минуту сайт открыт по адресу выше.

## Бот

Отдельный сервер боту не нужен — он просто открывает этот сайт.

**@BotFather** → `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → вставьте
`https://malik-alaska2.github.io/Qulay-Marketr/`

Теперь у бота внизу чата появится кнопка, открывающая каталог прямо в Telegram.

## Ссылки на позиции

Каждая позиция открывается по своему адресу: `.../Qulay-Marketr/#item-3`. Такую ссылку можно отправлять в переписке.

## Резервная копия

Это `catalog.json` и папка `photos/`. Они и так лежат в репозитории — история изменений хранится в самом GitHub.

Папка `catalog/` — версия на Next.js и SQLite, которой нужен свой сервер. Она больше не используется, но оставлена на случай, если понадобится вернуться.
