# Каталог

Личный каталог квартир и товаров: сайт, который открывается и в браузере,
и внутри Telegram, плюс простая админка по паролю.

Всё лежит в одном приложении Next.js. База — файл `data.db` рядом с проектом,
фотографии — папка `public/uploads`. Никаких серверов баз данных, контейнеров
и внешних сервисов.

## Запуск

Нужен Node 22.

```bash
cp .env.example .env      # придумайте ADMIN_PASSWORD и SESSION_SECRET
npm install
npm run dev               # http://localhost:3000
```

Таблица в базе создаётся сама при первом запуске.

Админка — `/admin`, вход по паролю из `.env`.

## Бот (по желанию)

Получите токен у @BotFather, впишите `BOT_TOKEN` и `PUBLIC_URL` в `.env`:

```bash
npm run bot
```

Бот отвечает на `/start` одной кнопкой, открывающей каталог.
Работает через long polling, поэтому домен и сертификат не нужны —
можно запускать даже с домашнего компьютера.

## Публикация

Подойдёт любой VPS с Node:

```bash
npm run build
npm start                 # порт 3000
```

Перед публикой поставьте что-нибудь для HTTPS (Caddy или nginx) и держите
`ADMIN_PASSWORD` подлиннее — вход в админку защищён только им.

Резервная копия — это `data.db` и папка `public/uploads`. Скопируйте их,
и переезд на другой сервер займёт пару минут.

## Что где

```
src/lib/db.ts            таблица и запросы
src/lib/auth.ts          вход по паролю
src/app/page.tsx         главная со списком и поиском
src/app/item/[id]        карточка позиции
src/app/admin            админка: список, форма, удаление
bot/bot.mjs              бот
```

## Если понадобится больше

Корзина, заказы, узбекский язык и онлайн-оплата сюда не входят намеренно.
Связь с покупателем идёт кнопкой «Написать в Telegram» — для личного
каталога этого достаточно, а сложность растёт быстро.
